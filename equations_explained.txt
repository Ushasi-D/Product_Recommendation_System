Based on the `colab_jsonl_category.ipynb` notebook, here are the exact equations and logic used for each of the three steps:

### 1. Sentiment Analysis
The sentiment analysis primarily uses a deep learning model rather than a simple mathematical equation. However, the final product score is calculated using an arithmetic mean:

*   **Prediction:** It uses the `LiYuan/amazon-review-sentiment-analysis` model (a fine-tuned RoBERTa transformer) to classify each review into a `1` to `5` star rating.
*   **Aggregation Equation:** For each product, it takes a sample of up to 30 reviews, runs them through the model, and averages the results:
    Calculated Sentiment Score = (Sum of Predicted Stars for all sampled reviews) / (Total Number of Sampled Reviews)

### 2. Feature Score Generation
The feature score is generated by calculating the sum of TF-IDF vectors for the product's descriptor (`brand` + `category` + `title`), and then normalizing that sum to a 1-to-5 scale.

*   **TF-IDF Sum (DocLen):** The sum of the TF-IDF weights for the product text.
*   **Normalization Equation (Min-Max Scaling):**
    Feature Score = 1 + 4 * ( (DocLen - Min(DocLen)) / (Max(DocLen) - Min(DocLen)) )
    *(If all products have the exact same sum length, it defaults to a score of 3.0.)*

### 3. Hybrid Ranking
The initial rank is a weighted combination of the calculated sentiment, the average Amazon star rating, and the feature score. The equation dynamically adjusts its weights based on which data points are available for a given product:

*   **Condition A (Has both Sentiment Score and Amazon Star Rating):**
    Rank = (0.6 * Sentiment) + (0.2 * Amazon Stars) + (0.2 * Feature Score)

*   **Condition B (Has Sentiment Score but NO Amazon Star Rating):**
    Rank = (0.7 * Sentiment) + (0.3 * Feature Score)

*   **Condition C (Has Amazon Star Rating but NO Sentiment Score):**
    Rank = (0.7 * Amazon Stars) + (0.3 * Feature Score)

*   **Condition D (Has neither):**
    Rank = Feature Score
