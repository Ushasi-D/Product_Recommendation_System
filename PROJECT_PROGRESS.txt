  REAL DATA PIPELINE & NLP
 ═══════════════════════════════════════════════════════════════════════════════════

  Step 4 ─── Google Colab NLP Pipeline (colab_pipeline.py / .ipynb)
  ├── Created a Python script to run on Google Colab with GPU support
  ├── Data Loading:
  │     ├── Loads 20191226-items.csv (product metadata: asin, brand, title, price, etc.)
  │     ├── Loads 20191226-reviews.csv (user reviews: asin, rating, body, etc.)
  │     └── Merges both CSVs on the 'asin' column after stripping whitespace
  ├── Sentiment Analysis:
  │     ├── Initially used BERT model for sentiment detection
  │     ├── ⚡ UPGRADED to RoBERTa model (LiYuan/amazon-review-sentiment-analysis)
  │     │     └── Reason: Better accuracy (95.14%) and improved sarcasm detection
  │     ├── Processes reviews in batches of 128 on GPU for speed
  │     └── Maps sentiment labels (1-5 stars) to numerical scores
  ├── Hybrid Score Calculation:
  │     ├── Feature Score: TF-IDF vectorizer on product text (brand + title)
  │     ├── Initial Rank formula:
  │     │     └── (0.6 × sentiment) + (0.2 × star_rating) + (0.2 × feature_score)
  │     └── Products ranked by initial_rank (higher = better recommendation)
  └── Output: processed_products.json
        └── Each product: id, title, brand, image, price, rating, review_count,
            calculated_sentiment_score, feature_score, initial_rank

  Step 5 ─── Backend Upgrade: TF-IDF Semantic Search
  ├── Replaced basic keyword matching with scikit-learn TF-IDF search
  │     ├── Builds an in-memory TF-IDF index on server startup
  │     ├── Uses cosine similarity to rank search results by relevance
  │     └── Fallback: includes exact keyword matches if TF-IDF score is low
  ├── Added In-Memory Caching:
  │     └── Loads processed_products.json ONCE on startup (fast access)
  ├── Added Sorting API Parameters:
  │     ├── rank_desc  → Highly Recommended First (default)
  │     ├── rank_asc   → Lowest Recommended First
  │     ├── price_low  → Price: Low to High
  │     └── price_high → Price: High to Low
  └── Installed scikit-learn as a new dependency

  Step 6 ─── Frontend: Product Cards & Search Integration
  ├── Updated ProductCard.jsx:
  │     ├── Mapped new JSON fields (rating, calculated_sentiment_score, initial_rank)
  │     ├── Added safe fallbacks for missing data (prevents crash on undefined)
  │     ├── Added image onError handler (shows placeholder if Amazon URL is broken)
  │     └── Dynamically shows "Features" section only when features exist
  ├── Updated App.jsx:
  │     ├── Fetches data from /api/recommendations?q=<query>&sort=<method>
  │     ├── Added currentQuery and sortMethod state variables
  │     └── Passes sort parameter to backend on every request
  └── Updated SearchBar.jsx:
        ├── Added a <select> dropdown for sorting options
        ├── Options: Highly Recommended, Lowest Recommended, Price Low/High
        └── Triggers re-fetch when user changes sort selection
